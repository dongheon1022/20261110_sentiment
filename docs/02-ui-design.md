# 02. UI 디자인 및 화면 구성

## 디자인 기준 이미지 해석

사용자가 제공한 참고 화면은 다음 특징을 가진다.

- 화면 전체가 차콜에 가까운 짙은 흑회색이다.
- 중앙에 눈 덮인 거대한 산봉우리와 하단의 침엽수 실루엣이 배치되어 있다.
- 상단 중앙에는 큰 세리프 대문자 워드마크 `ASCEN`이 있다.
- 색상은 차가운 회색·청회색·백색 위주이며, 장식과 UI 요소가 절제되어 있다.
- 분위기는 고요하고 웅장하며, 산 정상으로 올라가는 듯한 인상을 준다.

이 이미지는 **스타일 참고용**이다. 스크린샷 전체를 배경 이미지로 재사용하지 않는다.

## 화면 설계

MVP는 한 페이지로 구성한다.

1. **Hero / 브랜드 영역**
   - 상단 중앙에 `ASCEN` 워드마크.
   - 큰 산 이미지 또는 이미지가 없을 때의 CSS 산악형 그라데이션 배경.
   - 짧은 소개 문구: `문장에 담긴 감정의 결을 읽다.`와 같은 한국어 문구.
2. **입력 영역**
   - 여러 줄 텍스트 입력창.
   - 글자 수 `현재 / 5,000`.
   - `감정 분석하기` 버튼.
   - 입력한 텍스트가 저장된다는 안내.
3. **결과 영역**
   - 분석 전에는 숨기거나 비어 있는 상태.
   - 분석 후 긍정/부정/중립 라벨, 신뢰도, 이유 목록 표시.
   - 결과는 입력 영역 아래에 배치한다.
4. **상태 영역**
   - 로딩, 입력 오류, 서버 오류, 저장 실패 안내를 표시한다.

## 디자인 토큰

| 항목 | 기준 |
|---|---|
| 페이지 배경 | `#171A1B` |
| 보조 배경 | `#202629` |
| 패널 배경 | `rgba(13, 17, 19, 0.78)` |
| 기본 글자 | `#E8EDF0` |
| 보조 글자 | `#AAB5BC` |
| 강조색 | `#AFC4D0` |
| 테두리 | `rgba(220, 232, 240, 0.18)` |
| 제목 글꼴 | 사용 가능한 세리프 계열 |
| 본문 글꼴 | 시스템 산세리프 계열 |

정확한 폰트 파일이 제공되지 않았다면 외부 폰트 다운로드를 필수로 만들지 않는다. `Georgia`, `Times New Roman`, 시스템 세리프 등을 대체 글꼴로 둔다.

## 레이아웃 및 반응형

- 데스크톱: 중앙 정렬, 콘텐츠 최대 너비 약 760px.
- 모바일: 좌우 20px 이상 여백, 입력창과 버튼은 화면 너비에 맞춤.
- Hero는 첫 화면에서 브랜드와 산의 인상을 전달하되, 입력 기능이 과도하게 아래로 밀리지 않게 한다.
- 작은 화면에서 제목 크기와 Hero 높이를 줄인다.
- 버튼과 입력창은 충분한 대비와 터치 영역을 확보한다.
- 모션은 최소화하고 `prefers-reduced-motion`을 존중한다.

## 이미지 제약

- 실제 산 이미지 파일이 프로젝트에 제공되면 `public/images/hero-mountain.webp`를 사용한다.
- 파일이 없다면 임의의 외부 URL이나 깨진 이미지 경로를 만들지 않는다. CSS 그라데이션과 어두운 산 능선 형태로 대체한다.
- 이미지 위 텍스트는 대비가 충분해야 한다.
- 이미지 로딩 실패 시에도 배경색과 텍스트가 유지되어야 한다.

## 완료 기준

- 참고 이미지의 차콜 배경, 중앙 워드마크, 설산의 차가운 분위기가 전달된다.
- 텍스트 입력과 분석 버튼을 별도 설명 없이 알아볼 수 있다.
- 데스크톱 1440px 및 모바일 375px 너비에서 가로 스크롤이 없다.
- 로딩/결과/오류가 시각적으로 구분되고 색상 외 텍스트도 제공된다.
